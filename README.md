# VILAX — система управления сетью ресторанов

Отдельная версия сайта vilax.ai: атмосферный лендинг с живым WebGL-фоном (Three.js), стеклянными карточками и скролл-анимациями (GSAP + Lenis).

Превью: https://myatnyi-vibe.github.io/vilax-site-3d/

- Один статический файл `index.html`, без сборки; библиотеки — с jsDelivr.
- `shots/` и `shots-app/` — настоящие экраны VILAX на демо-сети (демо-данные).
- Формы на этой версии ничего не отправляют.
